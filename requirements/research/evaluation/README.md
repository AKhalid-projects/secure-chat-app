# Testing and evaluation (Chapter 7, academic prose)

This folder contains **report-style** material for **Testing and Evaluation** (thesis Chapter 7): a **planned methodology** for validating the Secure Chat Application against the analysed requirements (Chapter 4, [`../requirements-tables.md`](../requirements-tables.md)), the system design (Chapter 5, [`../design/academic-system-design.md`](../design/academic-system-design.md)), and the intended implementation (Chapter 6, [`../implementation/academic-implementation.md`](../implementation/academic-implementation.md)). The narrative emphasises **manual** and **inspection-based** verification consistent with **NFR-010** and **NFR-012**. Where execution is incomplete, **outcomes** in summary tables **will** remain **to be determined** or **to be recorded** at thesis completion.

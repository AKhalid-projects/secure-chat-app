# NFR-002: Error containment

The Secure Chat Application shall limit the blast radius of unhandled JavaScript errors by providing a React error boundary at the root and global error handlers for fatal errors and unhandled promise rejections at startup. Category: **reliability**; priority: **High**. Supervisor and risk-oriented discussion favoured graceful degradation over silent failure during demonstration.

The error boundary supplies a fallback render path; global handlers log faults for diagnosis without pretending to replace full production monitoring. Evidence appears in the error boundary module and entry script.

Confidence is **explicit**. Verification includes controlled fault injection in development only if ethically and safely contained, or review-led assessment of handler coverage.

**NFR-010** notes that observability remains limited to console-oriented diagnostics in this repository.

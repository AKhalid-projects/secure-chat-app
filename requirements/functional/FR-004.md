# FR-004: Builder configuration and theming

## 1. Requirement Statement

The Secure Chat Application shall load builder-style settings—including chat and call feature flags, layout tab order, brand colors, and typography— from a default JSON configuration and optional persisted overrides, and shall apply theme tokens to the CometChat theme provider.

## 2. Requirement Type

- Functional Requirement

## 3. Module / Domain

- Configuration

## 4. Description

A Zustand store (`useConfigStore`) initializes from `config.json`, then merges AsyncStorage `@app_config` when present (supporting both nested API `data` shape and plain config). `useConfig` selectors read `settings.layout.tabs`, `settings.style`, and feature blocks. `App.tsx` composes `CometChatThemeProvider` light/dark partial themes from `styleConfig` (brand color, text colors, typography via `createTypography`). `BottomTabNavigator` renders tabs in the order specified by `layout.tabs`.

## 5. Rationale

Allows “low-code” or builder-driven customization without code changes for many toggles and visual parameters.

## 6. Inputs

- `src/config/config.json`
- AsyncStorage `@app_config` (optional)
- `useConfigStore` update API

## 7. Processing / Behavior

1. On startup, async loader parses stored config or uses default JSON.
2. Store state updates `config`.
3. Components select slices of `settings` for UI and tabs.

## 8. Outputs

- Tab bar composition and labels driven by feature flags.
- CometChat theme colors and fonts aligned with `style`.

## 9. Preconditions

- Store initialization completes (default config always available).

## 10. Postconditions

- Running app reflects stored or default builder configuration.

## 11. Error Handling / Exceptions

- Parse errors fall back to default `config.json` (see `initializeConfig`).

## 12. Business Rules / Constraints

- Tab keys must map to known `TAB_COMPONENTS` entries in `BottomTabNavigator`.

## 13. Dependencies

- `zustand`, `@react-native-async-storage/async-storage`, `@cometchat/chat-uikit-react-native` theme types.

## 14. Evidence from Repository

- `src/config/store.ts`
- `src/config/config.json`
- `App.tsx` (theme composition)
- `src/navigation/BottomTabNavigator.tsx` (tabs)

## 15. Source Confidence

- **Explicit** — Full store and config wiring.

## 16. Acceptance Criteria

- Given no stored config,
- When the app starts,
- Then `config.json` defaults populate the store.

- Given `layout.tabs` lists `chats`, `calls`, `users`, `groups`,
- When the tab navigator renders,
- Then those tabs appear in that order.

- Given `style.brandColor` is set,
- When the theme provider renders,
- Then `CometChatThemeProvider` receives primary color from that brand color.

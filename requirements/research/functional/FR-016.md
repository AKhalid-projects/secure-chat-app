# FR-016: Notifications and deep linking

The Secure Chat Application shall display local notifications for incoming messages when appropriate, handle foreground and background notification interactions, and navigate users to relevant conversations or threads using payload data on Android and iOS. Priority is **High**; domain is **notifications**. Interview themes stressed the importance of opening the correct chat after an alert, not merely receiving a banner.

Foreground handlers, background handlers, and initial-notification checks participate in a coherent story. Active-chat context may suppress duplicate notifications when the user is already focused on a conversation. Evidence spans helper modules, the application shell, entry script background registration, and active-chat context.

Confidence is **explicit**. Verification combines device testing with inspection of payload parsing logic, noting that schema assumptions must match provider behaviour.

**FR-006** supplies navigation infrastructure; **FR-015** supplies token registration; **NFR-002** relates to reliability of deferred navigation.

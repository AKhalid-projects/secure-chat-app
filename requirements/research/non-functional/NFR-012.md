# NFR-012: Testability posture

The Secure Chat Application shall structure application logic into navigable modules and utilities to facilitate future automated testing, acknowledging that the analysed repository does not contain unit, integration, or end-to-end test suites for the Secure Chat Application. Category: **testability**; priority: **Medium**. Classification uses **inferred** confidence for the **gap** in automated tests while remaining explicit about modular structure where folders are visible.

The requirement supports an honest academic position: structural testability can exist even when test artefacts do not. Verification emphasises review of separation of concerns and hypothetical test seams rather than green CI badges.

**NFR-002** and **NFR-010** relate to runtime diagnosis versus systematic regression; future work may add Jest or device automation if module policy allows.

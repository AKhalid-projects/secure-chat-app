# FR-009: Message search

The Secure Chat Application shall allow users to search messages within a conversation context and to navigate from search results or threaded hits into the main message view or thread view with contextual parameters. Priority is **Medium**; domain is **messaging**. Participants associated search with discoverability in long conversations, which motivates treating it as a named functional obligation rather than an incidental UIKit default.

Search selection propagates identifiers and optional highlight keywords so that the user lands near the intended content. Evidence is concentrated in the search screen module and in navigation from messaging screens.

Confidence is **explicit** where search routes and handlers are implemented. Verification involves query submission, result selection, and observation of correct navigation parameters.

**FR-007** and **FR-008** provide the receiving contexts; **FR-006** supplies navigation infrastructure.

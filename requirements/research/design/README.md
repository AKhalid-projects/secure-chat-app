# System design (Chapter 5, academic prose)

This folder contains **pre-implementation system design** for the Secure Chat Application: report-style text aligned with Chapter 4 ([`../academic-requirements-gathering.md`](../academic-requirements-gathering.md), [`../academic-requirements-analysis.md`](../academic-requirements-analysis.md)) and with the **intended** decomposition suggested by the reference tree [`../../../`](../../../). The design is expressed in **future-oriented** language (what the system **will** provide and how it **will** be structured), consistent with a thesis chapter written **before** implementation is claimed complete.

## Relationship to requirements

Design obligations trace to [`../requirements-tables.md`](../requirements-tables.md). The matrix file is the explicit bridge between **analysed requirements** and **design artefacts**; the chapter narrative expands each subsection with diagrams and structured descriptions.

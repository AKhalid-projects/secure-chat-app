# NFR-010: Operational observability

The Secure Chat Application shall emit diagnostic information primarily through JavaScript console logging for errors, token lifecycle events, and handler failures, without an integrated application performance monitoring or centralised log shipping layer evidenced in the analysed codebase. Category: **observability**; priority: **Low** as framed in the index because the emphasis is on **limitation** rather than enterprise-grade telemetry.

This requirement is classified with **inferred** confidence regarding the **absence** of advanced tooling: the repository does not show attachment to a named observability vendor in the examined sources.

Verification is inspection-led and may include log capture during manual runs. The undergraduate report should position future monitoring as an enhancement if production operation were in scope.

**NFR-002** provides basic client-side containment; **NFR-012** relates to testability gaps.

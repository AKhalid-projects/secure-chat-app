# NFR-008: Technology stack compatibility

The Secure Chat Application shall declare and consume a fixed matrix of framework and library versions—including Expo, React Native, React, CometChat packages, Firebase modules, and native add-ons—such that builds remain reproducible within that matrix. Category: **compatibility**; priority: **High**. Undergraduate projects benefit from explicit version discipline because native stacks are sensitive to drift.

Evidence is found in package manifests and lockfiles; some dependencies use non-registry sources as declared. Confidence is **explicit**. Verification includes clean install and build attempts on supported toolchains.

**NFR-001** and **NFR-011** connect portability and integrability; **NFR-003** notes patch coupling to a UIKit version.

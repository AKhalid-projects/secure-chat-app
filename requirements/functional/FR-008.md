# FR-008: Thread replies

## 1. Requirement Statement

The Secure Chat Application shall support threaded conversations by navigating to a thread view for a parent message and displaying thread-specific message history in context.

## 2. Requirement Type

- Functional Requirement

## 3. Module / Domain

- Messaging

## 4. Description

`ThreadView` screen receives a parent message and optional user/group context. It uses CometChat UIKit patterns with `parentMessageId` semantics to show replies in a thread. Entry points include navigation from `Messages` and `SearchMessages` when a thread action is invoked.

## 5. Rationale

Threaded replies are a standard collaboration feature and are declared in builder config (`threadConversationAndReplies`).

## 6. Inputs

- `message` (BaseMessage), optional `user`/`group`, `highlightMessageId`.

## 7. Processing / Behavior

1. Navigate to `ThreadView` with params.
2. Render thread message list scoped to parent message id.

## 8. Outputs

- Thread UI showing reply stream.

## 9. Preconditions

- Parent message exists; user logged in.

## 10. Postconditions

- User can read or post replies in thread per UIKit capabilities.

## 11. Error Handling / Exceptions

- Standard SDK errors; UIKit handles empty states.

## 12. Business Rules / Constraints

- Thread availability may depend on `config.json` `threadConversationAndReplies` flag (product-level).

## 13. Dependencies

- CometChat UIKit thread list components, navigation types.

## 14. Evidence from Repository

- `src/components/conversations/screens/ThreadView.tsx`
- `src/navigation/types.ts` (`ThreadView` params)
- `src/components/conversations/screens/Messages.tsx` (navigation to thread)

## 15. Source Confidence

- **Inferred** — Thread screen is present and wired; exact UIKit capabilities follow vendor defaults.

## 16. Acceptance Criteria

- Given a message with replies,
- When the user opens the thread from Messages,
- Then `ThreadView` renders with the parent message context.

- Given navigation supplies `parentMessageId` semantics via UIKit,
- When the thread loads,
- Then replies associated with the parent are shown.

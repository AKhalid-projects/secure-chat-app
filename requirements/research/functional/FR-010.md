# FR-010: User directory and profiles

The Secure Chat Application shall present a list of users and detailed user information screens so that authenticated users can discover peers and open direct conversations or profile views. Priority is **Medium**; domain is **user management**. Stakeholder scope included directory-style access to users as a prerequisite for initiating chats outside pre-seeded test flows.

The user list screen navigates into messaging with appropriate parameters; profile screens consume user objects supplied through navigation. Evidence is found in user and user-info screen modules registered in the stack navigator.

Confidence is **explicit**. Verification includes list rendering, navigation into chat, and opening profile views from supported entry points.

**FR-007** receives navigation from directory actions; **FR-006** registers the routes.

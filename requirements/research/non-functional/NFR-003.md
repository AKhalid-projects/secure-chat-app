# NFR-003: Maintainability and vendor adaptation

The Secure Chat Application shall organise features into cohesive modules and shall apply controlled patches to third-party UIKit sources where upstream defects affect stability. Category: **maintainability**; priority: **Medium**. From an academic standpoint, this requirement documents **engineering discipline** in the face of vendor dependency: local patches are recorded and reapplied on install, which trades pristine dependency directories for predictable behaviour.

Evidence includes the patch directory and post-install script in package configuration. Confidence is **explicit** where the patch file exists. Verification ties to regression behaviour on navigation paths that previously triggered failures.

**FR-007** references the patched component class; **NFR-008** warns that upgrades require patch revalidation.

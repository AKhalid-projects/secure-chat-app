# FR-017: Encryption and privacy messaging UX

The Secure Chat Application shall display an encryption notice banner and an informational modal that explain end-to-end encryption and privacy of chats and calls in accessible language, with optional reference material via a learn-more link. Priority is **Medium**; domain spans **privacy** and **user experience**. User interviews requested **clarity** about privacy; the requirement deliberately frames **user-facing copy** rather than an independent cryptographic implementation within the project.

Banner and modal components are composed on the messaging screen; content is largely static in source. The thesis should not infer from this requirement alone that custom cryptographic protocols were engineered in the repository.

Evidence appears in dedicated banner and modal components and their use in the message screen. Confidence is **explicit** for the presence of the UX. Verification is qualitative: visibility, readability, and tap-to-open behaviour.

**FR-007** provides the host screen; **NFR-005** reminds readers that client-side security posture and vendor claims are distinct topics.

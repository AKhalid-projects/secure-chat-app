# NFR-001: Cross-platform deployment

The Secure Chat Application shall be deployable as native iOS and Android applications using Expo with a development client and a shared TypeScript and React Native codebase. This non-functional requirement sits in the **portability** category and carries **High** priority. Stakeholder discussion assumed demonstration on both major mobile ecosystems, which is a common constraint for undergraduate mobile projects.

Expo and React Native versions are declared in package manifests; platform identifiers appear in application configuration. Native modules such as Firebase and call integration imply use of a **development client** rather than a generic Expo Go runtime alone. Evidence is therefore manifest-level and dependency-level as well as procedural in the README.

The requirement is **explicitly** supported by configuration files. Verification combines manifest inspection with successful local builds where the environment permits. **NFR-008** and **NFR-009** elaborate compatibility and native capability declarations; **FR-001** depends on a runnable platform.

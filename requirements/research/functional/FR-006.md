# FR-006: Application navigation structure

The Secure Chat Application shall provide a stack-based navigator for authentication and feature screens and a bottom tab navigator for primary areas, with dynamic tab ordering based on configuration and an imperative navigation service that supports deferred navigation when the container is not yet ready. Priority is **High**; domain is **navigation**. User interviews emphasised predictable movement between chats, calls, users, and groups, which the tabbed pattern supports.

The stack coordinates credential entry, login, and deep feature routes including messages, threads, search, and call-related screens. Deferred navigation addresses practical constraints of push-driven entry before the navigation container finishes mounting, which is a common integration concern rather than a purely theoretical detail.

Evidence is distributed across stack and tab navigator modules and the navigation service. Confidence is **explicit**. Verification includes route reachability from documented entry points and correct processing of pending navigation after container readiness.

**FR-004** supplies tab keys; **FR-016** relies on navigation services for notification-driven transitions; **NFR-002** relates to reliability of navigation under asynchronous conditions.

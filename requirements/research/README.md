# Research narrative (academic report prose)

This folder holds **report-style** thesis drafts derived from the engineering requirement records in [`../functional/`](../functional/) and [`../non-functional/`](../non-functional/). The tone follows [`academic-requirements-gathering.md`](academic-requirements-gathering.md) and [`academic-requirements-analysis.md`](academic-requirements-analysis.md): formal **third person**, appropriate for an undergraduate final-year project, with **stakeholder-led elicitation** as the main source and **repository evidence** for validation. Editorial conventions are summarised in [`content/editorial-style-notes.md`](content/editorial-style-notes.md).

## Relationship to engineering records

Each file named `FR-XXX.md` or `NFR-XXX.md` under `../functional/` and `../non-functional/` retains the **full structured template** (acceptance criteria, evidence paths, and so on). The corresponding file under `research/functional/` or `research/non-functional/` is a **concise academic narrative** of the same obligation, not a replacement specification.

# FR-015: Push token registration

The Secure Chat Application shall obtain device push tokens (FCM on Android, APNs and VoIP on iOS) and register them with CometChat using configured push provider identifiers and helper routines. Priority is **High**; domain is **notifications**. Users expected alerts when the application is not in the foreground; token registration is the client-side obligation that enables provider-mediated delivery.

Platform-specific branches request permissions, listen for token events, and forward tokens through documented helpers. Constants supply provider identifiers for dashboard alignment. Evidence is distributed across notification helpers, the application shell, and constants.

Confidence is **explicit**. Verification includes observing token logs in controlled environments and confirming dashboard configuration matches identifiers, without overstating delivery guarantees.

**FR-003** gates registration timing; **FR-016** addresses notification presentation and interaction; **NFR-005** addresses credential and token handling qualitatively.

# FR-012: Call history and ongoing session

The Secure Chat Application shall present call history and call detail views and shall allow users to enter an ongoing call screen for active voice or video sessions managed through CometChat. Priority is **High**; domain is **calls**. Interview and workshop discussion treated voice and video as first-class expectations alongside text chat.

Call logs and detail screens consume SDK call records; the ongoing session screen hosts active media interaction consistent with WebRTC-oriented dependencies declared in the manifest. Evidence appears in call component modules and ongoing-call screen registration.

Confidence is **explicit**. Verification requires device or simulator runs with appropriate permissions and valid test accounts, acknowledging that media behaviour depends on network and provider conditions outside the repository.

**FR-013** and **FR-014** address incoming handling and native integration; **NFR-011** addresses third-party stacks.

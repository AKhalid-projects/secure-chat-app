# NFR-006: Visual theme alignment

The Secure Chat Application shall align CometChat UI theming—including primary brand colour and light and dark text colours—with configurable style tokens and system appearance where applicable. Category: **usability**; priority: **Medium**. Workshop participants associated visual consistency with perceived quality and readability.

Theme objects are composed from configuration-driven colour and typography helpers; platform user-interface style settings support automatic light and dark modes at the shell level. Evidence appears in the root application module, typography helper, configuration JSON, and application manifest.

Confidence is **explicit**. Verification is primarily visual and configuration-driven.

**FR-004** supplies style inputs; **NFR-007** addresses internationalisation separately.

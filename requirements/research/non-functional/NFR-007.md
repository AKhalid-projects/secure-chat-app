# NFR-007: Internationalisation support

The Secure Chat Application shall integrate CometChat’s internationalisation provider so that UI strings supplied by the UIKit can be translated according to CometChat internationalisation conventions. Category: **localisation**; priority: **Medium**. The requirement reflects vendor integration rather than a claim that every custom string in the project is fully translated.

The provider wraps the navigation tree; tab labels consume translation hooks. Custom screens may still contain hard-coded prose; academic discussion should state coverage honestly.

Confidence is **explicit** for provider usage. Verification includes changing device language and comparing vendor-controlled labels with custom text behaviour.

**NFR-006** relates to visual presentation; **FR-006** hosts translated tab labels where applicable.

# NFR-006: Visual theme alignment

## 1. Requirement Statement

The Secure Chat Application shall align CometChat UI theming—including primary brand color and light/dark text colors—with configurable style tokens and system appearance where applicable.

## 2. Requirement Type

- Non-Functional Requirement

## 3. NFR Category

- Usability

## 4. Description

`App.tsx` builds `CometChatThemeProvider` theme objects from `useConfig` style settings (`brandColor`, primary/secondary text for light and dark) and `createTypography` for font family selection. `app.json` sets `userInterfaceStyle` to `automatic` for OS-driven light/dark preference.

## 5. Rationale

Consistent branding and readable contrast improve user trust and accessibility of UI elements.

## 6. Quality Scenario

- **Source**: User switches OS theme.
- **Stimulus**: Dark mode enabled.
- **Artifact**: Chat screens.
- **Environment**: iOS/Android with automatic UI style.
- **Response**: CometChat theme uses dark text tokens.
- **Response Measure**: Visual inspection shows appropriate colors.

## 7. Measurable Criteria

- Theme object maps `styleConfig.color.*` fields; `app.json` declares automatic UI style.

## 8. Applicability

- All UIKit-themed screens under provider.

## 9. Constraints / Policies

- Font family limited to options supported by `themeTypography` helper.

## 10. Evidence from Repository

- `App.tsx`
- `src/utils/themeTypography.ts`
- `src/config/config.json`
- `app.json`

## 11. Source Confidence

- **Explicit** — Theme wiring is explicit.

## 12. Verification Approach

- Toggle system dark mode; inspect primary/text colors against config.

## 13. Risks if Unmet

- Poor readability or brand inconsistency across screens.

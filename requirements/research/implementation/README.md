# Implementation (Chapter 6, academic prose)

This folder contains **report-style** material for **Implementation** (thesis Chapter 6): how the Secure Chat Application **will** be realised in software in a way that **implements** the system design in [`../design/academic-system-design.md`](../design/academic-system-design.md) and remains traceable to Chapter 4 via [`../requirements-tables.md`](../requirements-tables.md). The narrative uses **planned / future-oriented** language (“the implementation will…”), consistent with a chapter drafted **before** final implementation is claimed complete.

## Relationship to design and code

Implementation descriptions **will** align with the **intended** layout under [`repository root`](../../../) without asserting that every path is finished or frozen. Chapter 5 remains the **design** authority; this chapter explains **how** that design **will** be carried into code and third-party integrations.

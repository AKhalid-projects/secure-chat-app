# FR-007: Conversations and messaging

## 1. Requirement Statement

The Secure Chat Application shall provide access to conversation lists and real-time messaging sessions for both one-to-one and group contexts using CometChat UIKit components integrated into the application screens.

## 2. Requirement Type

- Functional Requirement

## 3. Module / Domain

- Messaging

## 4. Description

The `Conversations` screen and `Messages` screen compose CometChat UIKit primitives (message list, composer, headers) to send and receive messages in a selected conversation. Navigation passes `user` or `group` (or serializable `userUid` / `groupGuid`) parameters. The feature enables the core chat experience advertised in the sample README.

## 5. Rationale

Primary value proposition of the Secure Chat Application is real-time messaging over CometChat.

## 6. Inputs

- Selected conversation or user/group identifiers from navigation params.
- Network connectivity to CometChat.

## 7. Processing / Behavior

1. Resolve `user`/`group` from params or SDK fetch by UID/GUID.
2. Render message list and composer via UIKit.
3. Send/receive messages through SDK.

## 8. Outputs

- Updated conversation history in UI; server-side persistence via CometChat.

## 9. Preconditions

- User logged in; valid receiver resolved.

## 10. Postconditions

- Messages visible in thread; UIKit patch guards against missing user/group when building requests (see patch).

## 11. Error Handling / Exceptions

- UIKit patch prevents null request builder when user and group absent (`patches/...CometChatMessageList.tsx`).

## 12. Business Rules / Constraints

- Feature flags in `config.json` may disable certain message types at product level (UIKit-dependent).

## 13. Dependencies

- `@cometchat/chat-uikit-react-native`, `@cometchat/chat-sdk-react-native`.

## 14. Evidence from Repository

- `src/components/conversations/screens/Conversations.tsx`
- `src/components/conversations/screens/Messages.tsx`
- `patches/@cometchat+chat-uikit-react-native+5.2.10.patch`

## 15. Source Confidence

- **Explicit** — Screens and UIKit integration are present.

## 16. Acceptance Criteria

- Given a logged-in user,
- When they open a conversation and send a text message,
- Then the message appears in the list and is delivered via CometChat SDK behavior.

- Given navigation includes `groupGuid`,
- When Messages loads,
- Then group messaging context is established.
